Politique de confidentialité

NetGuard Pro v3.0.0
Dernière mise à jour : 28 mars 2026

1. Introduction

NetGuard Pro est une suite de cybersécurité locale pour Windows développée par NetGuard. Cette politique décrit comment l'application traite vos données. NetGuard Pro fonctionne entièrement en local sur votre ordinateur.

2. Données collectées

Données traitées localement (jamais transmises)

  • Paquets réseau — analysés en temps réel par le moteur IDS/IPS pour détecter les menaces. Les données brutes restent sur votre machine.
  • Adresses IP — les IP source et destination du trafic réseau sont analysées localement pour la détection d'intrusions.
  • Journaux de sécurité — les alertes, menaces détectées et actions du pare-feu sont enregistrées dans des fichiers locaux.
  • Configuration — vos préférences, règles et paramètres sont stockés dans des fichiers JSON locaux.
  • Identifiants — le mot de passe administrateur du dashboard est stocké sous forme de hash SHA-256 en local.

Requêtes externes (optionnelles)

  • Géolocalisation d'IP — l'application peut interroger des services tiers (ipwho.is, ip-api.com, ipapi.co) pour localiser les IP sources de trafic. Seules les adresses IP publiques sont envoyées à ces services.
  • Flux de menaces — consultation de listes publiques de menaces (abuseipdb.com) pour enrichir la détection. Seules les IP suspectes sont vérifiées.
  • Mises à jour — vérification optionnelle des nouvelles versions disponibles.

Données NON collectées

  • Aucune donnée personnelle (nom, email, téléphone)
  • Aucune télémétrie ni analytics
  • Aucun suivi publicitaire
  • Aucun envoi de données à nos serveurs
  • Aucun cookie tiers

3. Stockage des données

Toutes les données sont stockées exclusivement sur votre ordinateur dans le répertoire d'installation (C:\Program Files\NetGuard Pro) :

  • netguard_settings.json — configuration
  • netguard_users.json — comptes utilisateurs (hachés)
  • logs/ — journaux de sécurité
  • captures/ — captures réseau
  • reports/ — rapports de sécurité

Aucune donnée n'est transmise à un serveur distant ou au cloud.

4. Partage de données

NetGuard Pro ne partage aucune donnée avec des tiers. Les seules communications réseau sont les requêtes de géolocalisation d'IP décrites ci-dessus, qui ne contiennent aucune information personnelle.

5. Sécurité

L'application utilise :

  • Hachage SHA-256 pour les mots de passe
  • Tokens de session avec expiration automatique (24h)
  • Communication locale uniquement (localhost)
  • Aucun port ouvert vers l'extérieur par défaut

6. Droits de l'utilisateur

Vous pouvez à tout moment :

  • Supprimer tous les journaux et captures via le dashboard
  • Réinitialiser la configuration aux valeurs par défaut
  • Désinstaller complètement l'application (supprime toutes les données)
  • Désactiver les requêtes de géolocalisation dans les paramètres

7. Enfants

NetGuard Pro est un outil de cybersécurité professionnel destiné aux utilisateurs de 16 ans et plus. L'application ne collecte aucune donnée sur les enfants.

8. Modifications

Cette politique peut être mise à jour lors de nouvelles versions. La date de dernière modification est indiquée en haut de cette page.

9. Contact

Pour toute question concernant cette politique :
Email : privacy@netguardpro.com

Privacy Policy

NetGuard Pro v3.0.0
Last updated: March 28, 2026

1. Introduction

NetGuard Pro is a local cybersecurity suite for Windows developed by NetGuard. This policy describes how the application handles your data. NetGuard Pro runs entirely locally on your computer.

2. Data Collected

Data processed locally (never transmitted)

  • Network packets — analyzed in real-time by the IDS/IPS engine to detect threats. Raw data stays on your machine.
  • IP addresses — source and destination IPs from network traffic are analyzed locally for intrusion detection.
  • Security logs — alerts, detected threats, and firewall actions are recorded in local files.
  • Configuration — your preferences, rules, and settings are stored in local JSON files.
  • Credentials — the dashboard admin password is stored as a local SHA-256 hash.

External requests (optional)

  • IP geolocation — the app may query third-party services (ipwho.is, ip-api.com, ipapi.co) to locate traffic source IPs. Only public IP addresses are sent to these services.
  • Threat feeds — public threat lists (abuseipdb.com) are queried to enhance detection. Only suspicious IPs are checked.
  • Updates — optional check for new available versions.

Data NOT collected

  • No personal data (name, email, phone)
  • No telemetry or analytics
  • No advertising tracking
  • No data sent to our servers
  • No third-party cookies

3. Data Storage

All data is stored exclusively on your computer in the installation directory (C:\Program Files\NetGuard Pro):

  • netguard_settings.json — configuration
  • netguard_users.json — user accounts (hashed)
  • logs/ — security logs
  • captures/ — network captures
  • reports/ — security reports

No data is transmitted to a remote server or cloud.

4. Data Sharing

NetGuard Pro does not share any data with third parties. The only network communications are the IP geolocation requests described above, which contain no personal information.

5. Security

The application uses:

  • SHA-256 hashing for passwords
  • Session tokens with automatic expiration (24h)
  • Local communication only (localhost)
  • No externally-facing ports by default

6. User Rights

You can at any time:

  • Delete all logs and captures via the dashboard
  • Reset configuration to default values
  • Completely uninstall the application (deletes all data)
  • Disable geolocation requests in settings

7. Children

NetGuard Pro is a professional cybersecurity tool intended for users aged 16 and older. The application does not collect any data about children.

8. Changes

This policy may be updated with new releases. The last modification date is shown at the top of this page.

9. Contact

For any questions about this policy:
Email: privacy@netguardpro.com
