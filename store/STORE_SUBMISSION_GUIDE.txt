GUIDE DE SOUMISSION MICROSOFT STORE
NetGuard Pro v3.0.0
══════════════════════════════════════════════════

ÉTAPE 1 — CRÉER LE COMPTE PARTNER CENTER
──────────────────────────────────────────
1. Aller sur https://partner.microsoft.com
2. Se connecter avec un compte Microsoft
3. Choisir "Individual" (19 USD une seule fois)
4. Nom d'affichage : "NetGuard"
5. Compléter la vérification

ÉTAPE 2 — CRÉER L'APPLICATION
──────────────────────────────
1. Partner Center → Apps and Games → + New product → App
2. Réserver le nom : "NetGuard Pro"
3. Type : Win32 app (pas MSIX/UWP)

ÉTAPE 3 — PROPERTIES (PROPRIÉTÉS)
──────────────────────────────────
- Category : Security
- Subcategory : PC protection
- Privacy policy URL : (héberger privacy_policy.html et mettre l'URL)
  Option A : GitHub Pages → push store/privacy_policy.html
  Option B : Hébergement gratuit sur netlify/vercel
- System requirements :
  - OS : Windows 10 version 1809+
  - Architecture : x64
  - RAM : 4 GB
  - Disk : 200 MB

ÉTAPE 4 — AGE RATING
─────────────────────
- Remplir le questionnaire IARC
- Voir : IARC_age_rating_answers.txt
- Rating attendu : PEGI 3 / Everyone

ÉTAPE 5 — STORE LISTING (FR)
─────────────────────────────
- Langue : Français (France)
- Nom : NetGuard Pro
- Description courte : (voir store_description_FR.txt)
- Description : (voir store_description_FR.txt)
- Screenshots : (voir section ci-dessous)
- Icône : store/StoreLogo_300x300.png
- Hero image : store/store_hero_1920x1080.png

ÉTAPE 5b — STORE LISTING (EN) — optionnel
──────────────────────────────────────────
- Ajouter langue : English
- Copier depuis store_description_EN.txt

ÉTAPE 6 — PACKAGES
───────────────────
1. Cliquer "Packages"
2. Type d'installeur : EXE
3. Uploader : dist/NetGuardPro_Setup_3.0.0.exe
4. Paramètres d'installation silencieuse :
   - Silent install :   /VERYSILENT /NORESTART /SUPPRESSMSGBOXES
   - Silent uninstall : "C:\Program Files\NetGuard Pro\unins000.exe" /VERYSILENT /NORESTART
5. Architecture : x64
6. Install behavior : Install for all users (requires admin)

ÉTAPE 7 — SCREENSHOTS
──────────────────────
Minimum 1 screenshot, recommandé 4-5.
Taille : 1366x768 ou 1920x1080 PNG

Screenshots à prendre (lancer NetGuard Pro puis captures) :
1. Dashboard principal — vue d'ensemble avec graphiques trafic
2. Packets Live — tableau de paquets avec barre de couleurs 10 niveaux
3. Carte mondiale — avec points et arcs de connexion
4. Onglet Menaces — avec barre de légende des couleurs
5. VPN WireGuard — configuration VPN (optionnel)

Astuce : Win+Shift+S pour capturer, coller dans Paint, sauver en PNG

ÉTAPE 8 — SUBMIT
─────────────────
1. Vérifier tous les champs
2. Cliquer "Submit to the Store"
3. Certification prend 1-3 jours ouvrables
4. Si rejeté : lire le rapport, corriger, re-soumettre

PARAMÈTRES INNO SETUP POUR INSTALL SILENCIEUSE
══════════════════════════════════════════════════

Le Store exige une install/désinstall silencieuse.
Inno Setup supporte déjà ces paramètres :

Install :   NetGuardPro_Setup_3.0.0.exe /VERYSILENT /NORESTART /SUPPRESSMSGBOXES
Uninstall : "C:\Program Files\NetGuard Pro\unins000.exe" /VERYSILENT /NORESTART

Tester avant soumission :
  1. NetGuardPro_Setup_3.0.0.exe /VERYSILENT /NORESTART
  2. Vérifier que C:\Program Files\NetGuard Pro\ existe
  3. "C:\Program Files\NetGuard Pro\unins000.exe" /VERYSILENT /NORESTART
  4. Vérifier que le dossier est supprimé
